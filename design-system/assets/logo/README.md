# Logo

Vector lockup of the TuinZorg DP logo: the hand holding a sprout (redrawn from the current logo as a 3.2px line drawing on a 64px grid), **TuinZorg DP** in Bricolage Grotesque 750 at 92% width, and the tagline **Tuinonderhoud met passie** in Figtree 550, all converted to paths. Built by `src/build_logo.py`. Pick by ground; never recolour.

- `tz-logo.svg`: forest-800 #224620 hand and words, leaf-600 #3D9141 sprout, sage-700 tagline. Light and Sand.
- `tz-logo-on-dark.svg`: sage-50 hand and words, leaf-400 #6CC570 sprout. Forest and dark photos.
- `tz-mark.svg`: the mark on a forest-700 rounded tile with a lime sprout, like the current logo's green square. Favicon, Google Business profile, social avatars.
- `tz-logo-mono-forest.svg`: all forest-800. Print, stamps, invoices.
- `tz-logo-mono-white.svg`: all white. Workwear, van lettering, photo overlays.

Minimum height 32px (the tagline becomes unreadable below that; use the mark alone under 32px). Clear space: the height of the T in TuinZorg on every side. Interim artwork: replace with the client's original vector when it exists.
