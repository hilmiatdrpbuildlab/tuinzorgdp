# Icons

47 Lucide icons (lucide-static 1.52.0, ISC licence), 24×24 grid, stroke 2, round caps and joins, `stroke="currentColor"`; two custom icons drawn on the same grid (`mower.svg`, `grass.svg`); four brand marks from Simple Icons (CC0, filled): `google`, `facebook`, `instagram`, `whatsapp`. The build inlines them as SVG so they take the text colour. Default size 20px (`.tz-icon`).

Fixed roles:
- Services: `mower` maaien, `grass` gazononderhoud, `shovel` onkruid, `scissors` snoeien, `fence` lamellen, `ruler` afboording, `layers` materialen, `sprout` anders.
- Actions: `arrow-right` in buttons and links, `send` on submit, `maximize-2` on gallery photos, `chevron-left`/`chevron-right` in the lightbox, `external-link` for Google.
- Contact: `phone`, `mail`, `map-pin`, `clock`, `whatsapp`.
- Content: `check` in lists, `star` and `quote` in reviews, `badge-check`, `handshake`, `message-circle`, `recycle`, `truck` for USPs and perks, `image-plus` in empty media slots, `upload` in the drop zone.
- Forms: `eye` / `eye-off` to show or hide a password.
- Status: `info`, `circle-check`, `triangle-alert`, `circle-x`; `loader-circle` for loading; `plus` in the FAQ; `menu`/`x` for the drawer.
